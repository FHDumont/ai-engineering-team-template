# Notas do repositório

Regras do projeto que não são do método: nomes, medidas e o que vale só aqui. A atualização do método não sobrescreve este arquivo. Este é o modelo do template; copie e preencha no repositório que adota ou atualiza o método.

## Nomes só deste repositório

Liste, um por linha e entre crases, os nomes que só existem neste repositório (produto, bot, serviço). O `.method/scripts/check-docs.sh` reprova o desenho, o `AGENTS.md` e as skills que citarem algum deles. Exemplo: `- \`NomeDoProduto\``. Sem nomes, deixe a lista vazia.

## Regras do projeto

Medidas e regras próprias (limites, convenções, o que o dono opera). Junte aqui o que estava no `AGENTS.md` antigo e não é do método.
